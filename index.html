Калькулятор ежедневных коммерческих активностей агента

Баллы за день → зона → количество лидов на следующий день
Красная: < 60
Жёлтая: 60–149
Зелёная: 150+

Автоматические баллы (CRM)

Начисляются при движении по воронке. В калькуляторе — для ручного ввода.

Ручные баллы (оффлайн)

Вносятся РОПом после проверки. В калькуляторе — для ручного ввода.

Антиактивности (Штрафы)

Вычитаются из итогового балла за день.
Итого баллов за день: 0
Регламент работы
  1. Агент заполняет отчёт в конце дня через автоматизацию Битрикс24.
  2. Отчёт приходит РОПу на согласование.
  3. РОП подтверждает → баллы зачисляются. Отклоняет → уведомление агенту.
  4. Зона за предыдущий день определяет количество лидов на следующий день.
  5. Категория агента (по задаткам за квартал) определяет качество лидов.
